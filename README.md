# Project Purpose
The purpose of this project is to strengthen JavaScript fundamentals by building a functional grade calculator that accepts user input, stores data, processes calculations, and displays results dynamically on the page.

### Core Features

- Add grades to an array
- Remove grades from the array
- Display entered grades on the page
- Calculate the average grade
- Find the highest grade
- Find the lowest grade
- Validate user input before storing it
- Display results dynamically in the UI
